# Network Security Scanner

A beginner-friendly Python network security project created by **Muhammad Zain Iqbal**.

## What it does
- Accepts a hostname or IP address.
- Scans a selected TCP port range.
- Displays open ports and labels common services.
- Saves the results to `scan_report.txt`.

## Skills demonstrated
Python, TCP/IP networking, sockets, port scanning, basic security assessment, report generation.

## Run it
Requires Python 3 and no external packages.

```bash
python scanner.py
```

For a safe demonstration, enter `localhost` as the target. Only scan systems you own or have explicit permission to test.
